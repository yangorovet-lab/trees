# Тихая роща

Помидоро-таймер, в котором за каждый сеанс фокуса растёт дерево. Остановил таймер — дерево перестало расти и осталось в лесу.

- 7 деревьев, нарисованных в SVG: дуб, ель, берёза, сакура, клён, пальма, кактус
- Таймер 15 / 25 / 45 / 60 минут или своё время
- Личный лес с историей сеансов (хранится в `localStorage`)
- Светлая и тёмная тема

## Запуск

Один файл без сборки: откройте `index.html` в браузере.
